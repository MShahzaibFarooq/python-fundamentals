# Lab 03 — Lists and Dictionaries

## Scenario

You are reviewing a small set of security events represented as Python dictionaries inside a list.

## Objectives

- Store repeated values in a list.
- Store structured event data in dictionaries.
- Count events by type.
- Filter high-risk events.
- Explain why lists and dictionaries are common in security automation.

## Steps

1. Run `examples/lists_and_dictionaries.py`.
2. Review the event list and dictionary structure.
3. Add one new event type.
4. Change the high-risk threshold.
5. Run the related tests.

## Expected learning

You should understand how Python collections help represent logs, alerts, users, assets, and findings.
