# Lab 04 — Functions and Loops

## Scenario

You are given simple log lines and need to process them using functions and loops.

## Objectives

- Write reusable functions.
- Loop over log entries.
- Count matching log lines.
- Extract usernames from failed login events.
- Format a small list of security findings.

## Steps

1. Run `examples/functions_and_loops.py`.
2. Review the functions in `src/functions_and_loops.py`.
3. Add one more log line.
4. Change the keyword being counted.
5. Run the related tests.

## Expected learning

You should understand how functions and loops form the base of log analyzers, report generators, and security automation scripts.
