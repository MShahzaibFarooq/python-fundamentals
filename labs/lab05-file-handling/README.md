# Lab 05 — File Handling

## Scenario

You are given a small text log file and need to read, search, and summarize it with Python.

## Objectives

- Write text to a file.
- Read file content.
- Search for important lines.
- Count basic log levels.
- Understand why file handling matters in cybersecurity.

## Steps

1. Run `examples/file_handling_basics.py`.
2. Open the generated `sample_output/week1_demo.log`.
3. Review the error line search.
4. Review the log summary.
5. Run the related tests.

## Expected learning

You should understand how file handling supports log analysis, reporting, and evidence collection.
