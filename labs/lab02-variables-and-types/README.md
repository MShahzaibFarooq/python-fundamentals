# Lab 02 — Variables and Data Types

## Scenario

You are reviewing a small login event and representing it with Python variables.

## Objectives

- Create string, integer, and boolean values.
- Convert text input into an integer.
- Use simple logic to calculate a practice risk score.
- Explain how basic data types appear in cybersecurity scripts.

## Steps

1. Run `examples/variables_and_types.py`.
2. Review the output.
3. Change the username, failed login count, and admin status.
4. Run the tests for `src/basic_types.py`.

## Expected learning

You should understand how beginner Python concepts connect to simple defensive automation.
