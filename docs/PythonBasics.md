# Python Basics

## Variables

A variable is a name that points to a value in memory.

```python
username = "alice"
failed_logins = 3
is_admin = True
```

## Basic data types

- `str` stores text.
- `int` stores whole numbers.
- `float` stores decimal numbers.
- `bool` stores `True` or `False`.
- `list` stores ordered collections.
- `dict` stores key-value data.

## Cybersecurity connection

Security scripts often use simple data types:

- usernames as strings,
- failed login counts as integers,
- account status as booleans,
- alerts as dictionaries,
- log entries as lists.

## Practice idea

Create variables for a login event and calculate a small risk score from failed login count and account type.
