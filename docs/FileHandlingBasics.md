# File Handling Basics

## Why file handling matters

Cybersecurity scripts often read and write files:

- log files,
- reports,
- configuration files,
- indicators of compromise,
- scan results,
- evidence notes.

## Core operations

- Create a file
- Write text
- Read text
- Search lines
- Summarize content

## Cybersecurity example

A beginner log script can read a log file and count:

- `INFO`
- `WARNING`
- `ERROR`

This is the first step toward log analyzers and security reporting tools.

## Practice task

Create a small log file, search for failed login lines, and generate a simple summary.
